Whisk & Brew is an independently designed and developed café discovery platform built from the ground up using semantic HTML5 and custom CSS3. Designed to deliver a warm, café-inspired digital experience, the project showcases a curated selection of coffee, cakes, pastries, cookies, desserts, and savory snacks through a highly polished user interface. The platform features organized multi-category menus, dynamic product cards complete with imagery and localized pricing, external links to trusted culinary sources, and subtle micro-interactions that enhance user engagement. Developed as a comprehensive, hands-on project, this repository represents a deep dive into responsive web design, cross-browser compatibility, and iterative UI/UX testing, serving as a practical application of modern front-end layout techniques and design principles.
